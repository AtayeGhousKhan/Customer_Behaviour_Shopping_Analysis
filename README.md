# Customer Shopping Behavior Analysis

## 📌 Overview
This project analyzes customer shopping behavior to identify purchasing patterns, sales trends, and business insights. It uses Python for data cleaning and exploratory data analysis (EDA), MySQL for SQL-based analysis, and Power BI for interactive dashboard development.

The objective is to transform raw customer data into meaningful insights that support data-driven business decisions.

## 📂 Dataset
The project uses `customer_shopping_behavior.csv`, which contains customer shopping information such as:

- Customer demographics
- Product categories and items purchased
- Purchase amounts and previous purchases
- Discounts and subscription status
- Shipping types and payment methods
- Customer ratings and reviews

## 🛠️ Tools & Technologies
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- MySQL
- Power BI
- Jupyter Notebook

## 🔄 Project Workflow

### 1. Data Loading
- Imported the dataset into Python using Pandas.
- Inspected the dataset structure, columns, and data types.

### 2. Data Cleaning
- Checked for missing values and duplicate records.
- Reviewed data types and inconsistencies.
- Prepared the dataset for analysis.

### 3. Exploratory Data Analysis (EDA)
- Analyzed customer purchasing patterns.
- Explored product categories and customer preferences.
- Examined purchase amounts, discounts, and customer ratings.

### 4. SQL Analysis
- Created and managed the `customer_behavior` database in MySQL.
- Used SQL queries, aggregate functions, subqueries, CTEs, and window functions.
- Analyzed revenue, customer segments, product performance, and purchasing behavior.

### 5. Power BI Dashboard
- Connected the analyzed data to Power BI.
- Created interactive visualizations and KPI cards.
- Developed a dashboard to explore customer behavior and sales performance.

## 📊 Dashboard
The Power BI dashboard provides insights into:

- Revenue by gender and age group
- Customer purchasing patterns
- Product performance and average ratings
- Discount usage and purchase behavior
- Customer subscription status
- Shipping type and average purchase amount

## 📈 Key Analysis
The project explores important business questions, including:

- Which customer groups generate the highest revenue?
- Which products have the highest average ratings?
- Do subscribed customers spend more?
- Which products have the highest discount usage?
- How can customers be segmented based on purchase history?
- Which products are most frequently purchased within each category?

## 🚀 How to Run

### Prerequisites
- Python 3.x
- Jupyter Notebook
- MySQL Server
- MySQL Workbench
- Power BI Desktop

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/AtayeGhousKhan/Customer-Shopping-Behavior-Analysis.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Customer-Shopping-Behavior-Analysis
   ```

3. Install the required Python libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn
   ```

4. Open the Jupyter Notebook:

   ```bash
   jupyter notebook Customer_Shopping_Analysis.ipynb
   ```

5. Run the notebook cells to load, clean, and analyze the dataset.

6. Open `sql file.sql` in MySQL Workbench and execute the SQL queries.

7. Open `customer_shopping_analysis.pbix` in Power BI Desktop to explore the interactive dashboard.
